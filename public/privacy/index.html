プライバシーポリシー

trinitrotorol.com と mhwilds.trinitrotorol.com で扱う情報と、利用者が確認・削除できる範囲を説明します。

最終更新：2026年10月8日

運営者と対象

運営者は trinitrotorol です。この方針はtrinitrotorol.com の案内・攻略ページと、mhwilds.trinitrotorol.com の MHWILDS ツールを対象とします。外部リンク先での情報の扱いは、それぞれのサービスの方針に従います。連絡先はお問い合わせページをご覧ください。

MHWILDS の所持品と検索

所持品チェッカーは、装飾品・固定護石の数量、鑑定護石の能力とラベル、プロフィールの識別情報、更新日時などを、このサイトに割り当てられたブラウザの保存領域（localStorage）に保存します。登録した情報は同じブラウザのスキルシミュレーターで利用されます。

現在の公開設定では、装備検索をブラウザ内で計算します。検索条件や所持情報を計算用サーバーへ送る機能は有効化していません。ただし、ページやカタログの読み込みには配信元との通信が発生します。

JSON の書出しと取込みはブラウザ内で処理されます。ダウンロードしたファイルは利用者の管理となります。ラベルなどに個人情報を含めないこと、ファイルを共有する前に内容を確認することをお勧めします。

旧URLと新URLの保存領域は別です。旧データを引き継ぐには、JSONによる移行手順を利用してください。データをURLに含めたり、移行用サーバーへ送信したりはしません。

保存データの削除と持ち出し

チェッカーの「JSONをダウンロード」で所持情報を保存し、別のブラウザでは「JSONから復元」で取り込めます。端末・ブラウザ間の自動同期や、運営者側の復元用バックアップはありません。

「所持情報を初期化」は登録を空にします。破損した元データが復旧用に残る場合もあるため、保存領域全体を削除したい場合は、ブラウザ設定からこのサイトのデータを削除してください。端末にダウンロードした JSON は別に削除する必要があります。

ブラウザのデータ削除、プライベートブラウジングの終了、ブラウザ側の保存領域整理などで、保存情報を利用できなくなることがあります。必要な情報は削除前に書き出してください。

Exponential Idle ツールの設定と盤面

Exponential Idle ミニゲーム攻略・ソルバーは、表示言語と Arrow の表示方法の選択を、このサイトに割り当てられたブラウザの保存領域（localStorage）に保存します。設定を消去したい場合は、ブラウザ設定からこのサイトのデータを削除できます。trinitrotorol.com のサイトデータを削除すると、旧URLで保存した MHWILDS 所持情報にも影響します。移行前の情報が必要なら先に JSON を保存してください。新URLの所持情報は mhwilds.trinitrotorol.com の保存領域で管理されます。

入力した盤面と計算した解法は開いているページ内で扱い、現在の実装では永続保存しません。解法はブラウザ内で計算し、盤面を計算用サーバーへ送信しません。ページの配信とアクセス解析については、次の説明が適用されます。

ページ配信とアクセス解析

本サイトは Cloudflare を利用して配信しています。通信や安全な配信のために IP アドレス、アクセスした URL、ブラウザなどの技術情報が Cloudflare で処理される場合があります。サービス提供元の取扱いはCloudflare のプライバシーポリシーをご確認ください。

トップページや攻略・案内ページでは Cloudflare Web Analytics を使用し、ページ閲覧や読み込み性能を集計します。Cloudflare はこの Web Analytics について Cookie や localStorage を解析目的に使用しないと説明しています。詳細は収集方法の公式説明を参照してください。

MHWILDS の新サイトには Web Analytics の計測コードを設置していません。旧サイトの所持品チェッカーとスキルシミュレーターのパスも、自動挿入による計測を除外しています。この除外は、ページ配信そのものの通信がなくなるという意味ではありません。

広告について

現在、当サイトでは広告を配信していません。Google AdSense のサイト確認用情報を設置していますが、確認用情報だけで広告が表示されることはありません。

今後 AdSense を導入して広告を配信する場合、Google を含む第三者配信事業者が Cookie、ウェブビーコン、IP アドレス等を利用し、当サイトや他サイトへのアクセスに基づく広告の配信、効果測定、不正利用の防止のために情報を処理することがあります。広告の種類や同意の選択によって、扱う情報が異なります。

Google の情報の扱いはGoogle のサービスを使用するサイトやアプリから収集した情報の使用とGoogle プライバシーポリシーを参照できます。パーソナライズ広告はGoogle の広告設定で管理できます。第三者配信事業者による広告の選択についてはDigital Advertising Alliance の選択ページも参照できます。

広告配信を始める際は、本ページを実際の配信内容に合わせて更新し、対象地域で必要な同意の選択手段を用意します。ブラウザでも Cookie を管理できますが、Cookie の制限だけで全ての情報処理を停止できるとは限りません。

お問い合わせと外部サービス

お問い合わせは GitHub Issues を利用します。投稿内容や GitHub 上のユーザー名などは公開され、運営者が確認できます。問い合わせの対応や不具合の修正に利用します。投稿・アカウント情報の扱いはGitHub のプライバシー声明をご確認ください。

氏名、メールアドレス、所持品の全データなどを投稿する必要はありません。公開したくない内容を含めずに窓口へお知らせください。

方針の変更

保存の仕組みや外部サービスの利用が変わった場合は、このページを更新します。重要な操作の前に、更新日と該当する説明をご確認ください。
