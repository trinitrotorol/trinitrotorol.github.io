MHWILDS guide
Inventory and equipment search

日本語English

Use this guide to find out whether the decorations and charms you own can activate the skills you need. You can also search the catalog without using your inventory.

Instructions checked: October 13, 2026 · Applies to the current public browser version

  2. Register your inventory

1. Use each tool for its purpose

The Inventory Checker records decoration and crafted charm quantities, and the abilities of appraisal charms. The Skill Simulator finds equipment combinations for your weapon type and skill requirements.

Open both tools on mhwilds.trinitrotorol.com in the same browser on the same device. Your inventory is not automatically available on another device or in another browser. Use the JSON backup described below to transfer it.

In either tool, choose English in the 言語 / Language selector. The setting is shared by the two tools on the same site in this browser, when browser storage is available. Opening this English guide does not change the tools’ language automatically.

2. Register your inventory

Decorations and crafted charms

Choose Decorations or Crafted charms in the checker, then search by name, ID or skill. Enter an item’s quantity to save it automatically in this browser. A quantity of 0 means you do not own the item. You can also record multiple copies of a crafted charm.

Check the save status at the top of the page after making changes. If you see Unsaved changes or Save conflict · Not saved, follow the on-screen instructions and export your changes to JSON before closing the page.

Appraisal charms

Choose Appraisal charms, then + Add appraisal charm. Enter the skills, levels, slots and rarity shown in the game. You can save a charm that meets the current validation rules, then edit, duplicate or delete it.

Charms registered as separate instances remain separate, even if they have similar abilities. If a combination is rejected, first check the abilities in the game. If you suspect a missing validation rule, report it (Japanese contact page) with the abilities and catalog version.

Start with a few items

You can add more items later. However, a search with Use owned inventory treats unregistered decorations as having a quantity of 0. Start by checking the decorations likely to be needed and the charms you want to use, so that missing entries are easier to spot.

3. Set search conditions

Required skills and preferred skills

Required skills
Every specified minimum level must be met. Builds that do not meet these requirements are excluded.
Preferred skills
Among builds that meet the requirements, the search favors higher combined skill levels toward your specified targets. Adding a preferred skill does not make its target level mandatory.

If you must have a skill at Lv. 3, add it to Required skills. If you would like to raise another skill when possible, add it to Preferred skills. Start with your essential requirements and add more after looking at the results, rather than making everything mandatory at once. This makes each condition’s effect easier to understand.

Weapon type, inventory and result count

  1. Select a Weapon type if needed. Any leaves weapon types unrestricted.
  2. Select Use owned inventory to search with your items. Unregistered decorations count as 0, and only registered charms are used. This feature does not record whether you own or can craft weapons or armor.
  3. Set Maximum results from 1 to 20. Start with a small number to check your conditions.
  4. Select Search. Use Cancel search if you want to stop and revise the conditions.

The current public version calculates in your browser. Even if you select Use server if available; otherwise use browser, it uses your browser because server search is not currently enabled. Search time depends on your device and the conditions.

4. Read the results and understand the limits

Each candidate shows Equipment, Decorations and Active skills. Check which piece of equipment and which slot each decoration uses. Weapon decorations and armor decorations use different slot types.

The Preference score compares candidates against the preferences you entered. It is not an attack power or actual damage ranking. Check activation conditions in the game and how the skills fit your play style, even when the skill names match.

If there are no candidates, review required conditions one at a time, before preferred conditions. If searching without inventory produces candidates, quantities or registered charms may be limiting the search. A build found with relaxed conditions may not be possible with your current items.

5. Back up and restore with JSON

Choose Download JSON in the checker to save a backup. Do this before changing devices, clearing browser data or making extensive charm edits, so that you retain your previous entries.

On the destination device or browser, choose Restore from JSON. The checker validates the file and opens a confirmation view. Check the counts and warnings before choosing a method.

Merge with current inventory
For each ID, merging keeps the larger quantity instead of adding quantities. If you currently have 2 and the backup has 3, the result is 3. A merge is blocked if the same appraisal charm ID has different abilities.
Replace all inventory with the backup
This replaces your current entries with the backup. If you also need the current entries, save them to a separate JSON file first.

Different appraisal charm IDs remain separate instances even when their abilities match. If saved data is damaged, a standard JSON download does not include the damaged original data. Use Export original saved data when that option is shown to preserve it.

Move saved data from the old URL

The Wilds tools have moved to mhwilds.trinitrotorol.com. Browser storage on the old and new sites is separate, so your previous inventory does not appear automatically. The move did not delete your old data.

  1. In the browser and on the device you used before, open the Inventory Checker on the old site and choose Download JSON.
  2. Open the Inventory Checker on the new site, choose Restore from JSON, and select the saved file.
  3. Review its contents and warnings, then choose merge or replace. If you already have entries on the new site, back those up to JSON first.

The old site also has its own language setting. Select English under 言語 / Language there if you want the English button labels used in these instructions.

If the old site reports damaged data, use Export original saved data to preserve it. Do not clear the browser’s site data until you have checked that the transfer succeeded. Continue registering and editing items on the new site afterward.

6. Handle catalog changes and save errors

When the saved and current catalog versions differ

IDs missing from the current catalog and appraisal charms that cannot be validated under the current rules are kept, with warnings. They may be unavailable for search, so review the affected entries. Check them in the Inventory Checker and use Update catalog reference. If the simulator asks you to acknowledge exclusions, review the affected items before continuing.

Save conflicts and storage errors

Editing the same inventory in several tabs at once can cause a save conflict. Export unsaved changes to JSON, choose Load the latest saved data to review the current state, then merge. If browser storage is unavailable, check your browser’s privacy settings as well.

Data sources and reports

Equipment and skill data use MHDB, and appraisal charm validation refers to publicly available reverse-engineering information. See data sources and update policy (Japanese) for details. If a problem persists, send the catalog version, steps and specific inputs through the contact page (Japanese). You do not need to publish your entire backup or personal information.
