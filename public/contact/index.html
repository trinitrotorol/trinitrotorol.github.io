お問い合わせ・不具合報告

不具合、掲載内容の誤り、改善の提案は GitHub Issues へお寄せください。内容に応じて、次の窓口を選べます。

投稿した内容は公開されます

GitHub のアカウントが必要です。氏名、メールアドレス、パスワードなどの個人情報や、公開したくない内容を含めないでください。所持品のバックアップ JSON を丸ごと添付する必要はありません。

連絡先を選ぶ

MHWILDS スキルシミュレーター検索条件、検索結果、スキル・装備データについて。MHWILDS 所持品チェッカー登録、保存、JSON の取込・書出し、鑑定護石について。Exponential Idle 攻略・ソルバー盤面の入力や解法の表示について。サイト全体・その他の問い合わせ記事の訂正、リンク切れ、運営・プライバシーについて。

不具合報告にあると助かる情報

  1. 問題が起きたページの URL と、大まかな発生日時。
  2. 端末、OS、ブラウザの種類。分かる範囲で構いません。
  3. 問題が起きるまでの操作と、表示されたエラー。
  4. 期待していた結果と、実際の結果。
  5. MHWILDS の場合はカタログ版、対象の装備・装飾品・スキル、検索条件。

画像を添える場合は、アカウント名や別のタブ、個人情報が写っていないか確認してください。再現に必要な最小限の情報で十分です。

プライバシーに関する連絡

このサイトでの情報の扱いはプライバシーポリシーに記載しています。公開するべきでない情報を含む問題は、その情報自体を投稿せず、問題の種類だけをサイト全体の窓口にお知らせください。個別の返信時間はお約束していません。
