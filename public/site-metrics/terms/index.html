利用条件

アプリ概要・プライバシーポリシー・利用条件

この利用条件は、運営者専用アプリ「trinitrotorol Site Metrics」の利用範囲を説明します。

更新日：2026年10月13日

対象者と提供範囲

本アプリは trinitrotorol の運営者本人が、自分の Google アカウントでアクセスを許可した AdSense データを確認するために利用します。一般ユーザー向けのログインサービスや、他の方の Google データを取得するサービスは提供しません。

利用料金の徴収、広告の配信、広告設定や支払い情報の変更を行う機能はありません。

利用目的と Google API

読み取ったサイト状態と広告実績の集計は、運営者によるサイト改善のために使用します。Google API の利用では、Google APIs 利用規約およびGoogle API Services User Data Policyなど、適用される Google の条件に従います。

本アプリは Google が提供・運営するアプリではありません。表示される内容は API から取得した時点・対象期間の情報です。

データの取り扱いと利用停止

取得する情報、認可情報の保存、分析、連携解除と削除の方法は、このアプリのプライバシーポリシーに記載しています。

運営とお問い合わせ

運営者は trinitrotorol です。問い合わせは既存のお問い合わせ窓口をご利用ください。
