MHWILDS は、登録から検索へ。

まず所持品を登録し、必要なスキルだけで検索します。候補を見ながら優先スキルを加えると、条件を絞り込みやすくなります。

MHWILDS の使い方を読む
  1. 手持ちを登録する装飾品・固定護石・鑑定護石をゲーム内で確認。
  2. 必要なスキルで探す必須条件と優先条件を分けて指定。
  3. 結果と保存状態を確認する装飾品の配置を確認し、所持情報を JSON で退避。

使う前に知っておきたいこと

所持品は使っているブラウザに保存

MHWILDS の登録情報は端末間で自動同期されません。ブラウザの保存データを削除する前に、チェッカーから JSON をダウンロードしてください。
