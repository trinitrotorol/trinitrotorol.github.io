このサイトについて

trinitrotorol は、ゲーム内の情報を整理し、条件を比べるための攻略ツールを公開する個人サイトです。

運営者と目的

運営者は trinitrotorol です。MHWILDS の所持品管理と装備検索、Exponential Idle のミニゲーム解法を、ブラウザから利用できる形で公開しています。

ツールの出力だけで判断しづらい場面を減らすため、操作手順、保存の仕組み、検索結果の限界を合わせて説明します。問い合わせと修正依頼は GitHub Issues の窓口で受け付けています。

MHWILDS データの出典

装備・スキル・装飾品などの収録データには MHDB を使用しています。鑑定護石の組み合わせ検証では、公開解析シートおよび解析に関する公開投稿を参照しています。

コミュニティの収集・解析結果を含むため、ゲーム本体の公式仕様書としては扱っていません。出典にない組み合わせや、更新によって変わった内容を正しく扱えない場合があります。

現在配信中の版はチェッカーの「カタログ・保存情報」と、公開データの版情報（JSON）で確認できます。ゲーム内と違う場合は、カタログ版と具体的な装備・スキルの情報を添えてお知らせください。

更新と訂正

収録データの出典と入力条件を確認し、再現できた不具合や説明の誤りを修正します。ゲーム更新と同時にデータが更新されること、すべての組み合わせを収録していることは保証していません。

登録済みの所持品と新しいカタログの間に違いがある場合、MHWILDS ツールは内容を確認するための警告を表示します。更新前後の大切な所持情報は JSON で保存してください。カタログ変更時の対応も参照できます。

非公式ツールとしての位置付け

本サイトは各ゲームの開発元・販売元が運営する公式サイトではなく、提携や公認を示すものではありません。ゲーム名、装備名などの権利は各権利者に帰属します。

装備候補は指定条件と収録データをもとにした結果です。プレイ時の強さ、操作感、ダメージ量を保証するものではありません。実際に装備を作る前に、ゲーム内の能力とスロットを確認してください。

使いやすさと運営について

案内ページはデジタル庁デザインシステムを参考に、読みやすい文字、見分けやすいリンク、キーボードで確認できるフォーカスを用いています。デジタル庁による提供・認証を意味するものではありません。

現在、当サイトでは広告を配信していません。今後 Google AdSense を導入する場合は、広告枠と説明を区別し、プライバシーポリシーと必要な同意設定を更新します。
