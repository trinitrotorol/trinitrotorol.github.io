MHWILDS GUIDE

MHWILDS の使い方
所持品登録と装備検索

「持っている装飾品と護石で、必要なスキルを発動できるか」を調べるためのガイドです。所持品を使わず、収録データから候補を探すこともできます。

1. 2つのツールの役割を分ける

所持品チェッカーは、装飾品・固定護石の数量と鑑定護石の能力を記録する場所です。スキルシミュレーターは、武器種やスキル条件から装備の組み合わせを探す場所です。

両方を同じ端末・同じブラウザの mhwilds.trinitrotorol.com で開いてください。別の端末やブラウザでは、同じ所持情報は自動的に読み込まれません。移行には後述の JSON バックアップを使います。

所持品を登録する装備を検索する

2. 所持品を登録する

装飾品と固定護石

チェッカーで「装飾品」または「固定護石」を選び、名称・ID・スキルで検索します。対象の数量を入力すると、このブラウザに自動保存されます。0 個は未所持として扱われます。固定護石も複数個の数量を保持できます。

登録後はページ上部の保存状態を確認してください。「未保存の変更あり」「保存競合」などが表示される場合は、そのまま画面を閉じず、表示される案内に従って JSON を退避してください。

鑑定護石

「鑑定護石」から「＋ 鑑定護石を登録」を選び、ゲーム内で確認したスキル、レベル、スロット、レア度を入力します。現在の検証ルールに一致した個体を保存できます。登録後は編集・複製・削除ができます。

似た能力の護石でも、別の個体として登録したものは別に扱われます。入力した組み合わせが受け付けられない場合は、まずゲーム内の能力を確認してください。収録ルールの不足が疑われるときは、能力とカタログ版を添えて報告できます。

少しずつ登録して始める

登録は後から追加できます。ただし「所持品を考慮する」を選ぶ検索では、未登録の装飾品は 0 個です。最初は検索に使いそうな装飾品と、使いたい護石を確認すると登録漏れを見つけやすくなります。

3. 検索条件を決める

必須スキルと優先スキルの違い

必須スキル
指定した最低レベルを、すべて満たす必要があります。これを満たさない構成は候補に入りません。
優先スキル
必須条件を満たす構成の中で、指定した目標に向けて合計レベルの高い構成を優先します。優先に入れただけでは、目標レベルの達成が必須にはなりません。

例えば「このスキルの Lv.3 は必ず必要」であれば必須に設定します。「別のスキルも可能なら伸ばしたい」であれば優先に設定します。初めから全てを必須にせず、譲れない条件から検索し、結果を見て追加すると条件の影響が分かりやすくなります。

武器種・所持品・件数

  1. 必要に応じて武器種を選びます。「指定なし」では武器種を絞りません。
  2. 手持ちで探す場合は「所持品を考慮する」を選びます。未登録の装飾品は 0 個、護石は登録している個体を使って検索します。この機能は武器や防具の生産・所持状況を登録するものではありません。
  3. 表示件数を 1〜20 件から選びます。最初は少ない件数で条件を確認できます。
  4. 「検索する」を選びます。途中で条件を見直すときは「検索を中断」を使います。

現在の公開版はブラウザ内で計算します。計算方法に「利用可能ならサーバー、利用できなければブラウザ」を選んでも、現在サーバー検索は有効化されていないためブラウザを使用します。端末の性能や条件によって探索時間は変わります。

4. 結果を読み、限界を確認する

各候補には「装備」「装飾品」「発動スキル」が表示されます。装飾品は、どの装備の何番目のスロットに配置されるかまで確認してください。武器用と防具用の装飾品は別のスロット種別として扱われます。

「優先スコア」は入力した優先条件に対する比較値です。攻撃力や実戦のダメージ順位ではありません。スキル名が同じでも、ゲーム内での発動条件や自分の立ち回りは別に確認してください。

表示メッセージの読み方
表示意味と次の操作
候補が表示された表示された装備と装飾品の配置を確認します。武器・防具を実際に所持または生産できるかはゲーム内で確認してください。
表示上限まで候補を表示すべての組み合わせを列挙したという意味ではありません。表示件数やスキル条件を調整して比較します。
時間内に探索が完了しなかった探索途中の結果です。候補が 0 件でも、条件を満たす構成が存在しないと断定できません。
条件を満たす構成が見つからなかった入力条件と収録データでの結果です。必須レベル、装飾品の登録漏れ、護石の能力、カタログ版を確認します。

候補が出ないときは、まず優先条件ではなく必須条件を 1 つずつ見直します。所持品を考慮しない検索で候補が出る場合は、所持数や登録した護石が制約になっている可能性があります。条件を緩めた結果が、現在の手持ちでそのまま組めるとは限りません。

5. JSON で保存・復元する

チェッカーの「JSONをダウンロード」でバックアップを保存します。端末変更、ブラウザのデータ削除、護石の大量編集の前に保存しておくと、元の登録内容を残せます。

復元先で「JSONから復元」を選ぶと、内容を検証したうえで確認画面が開きます。表示された件数や警告を確認して、次の方法を選んでください。

現在の所持情報と統合
同じ ID の所持数は加算せず、多い方を採用します。たとえば現在 2 個、バックアップ 3 個なら 3 個です。同じ鑑定護石 ID で能力が異なる場合は統合を中止します。
バックアップで全体を置換
現在の登録を、バックアップの内容に入れ替えます。現在の情報も必要なら、先に別の JSON として保存してください。

別の鑑定護石 ID は、能力が同じでも別個体として扱います。データが破損している場合、通常の JSON ダウンロードに破損した元データは含まれません。画面に「元の保存データを退避」が出ている場合は、その機能を使って元データを残してください。

旧URLの保存データを移す

ワイルズのツールは mhwilds.trinitrotorol.com に移転しました。旧サイトと新サイトのブラウザ保存は別のため、以前の所持情報は自動では表示されません。旧データは削除していません。

  1. 以前使っていた端末・ブラウザで旧サイトの所持品チェッカーを開き、「JSONをダウンロード」で保存します。
  2. 新サイトの所持品チェッカーで「JSONから復元」を選び、保存したファイルを指定します。
  3. 内容と警告を確認し、統合または置換を選びます。新サイトにすでに登録がある場合は、その内容も先にJSONで保存してください。

旧サイトに破損データの表示がある場合は「元の保存データを退避」で元データを残してください。移行を確認するまでブラウザのサイトデータを削除しないでください。移行後は新サイトで登録・編集を続けてください。

6. カタログ変更・保存エラーへの対応

「保存時と現在のカタログの版が異なる」とき

現在のカタログにない ID や、現在のルールで検証できない鑑定護石は、登録内容を保持したまま警告されます。検索では利用できない場合があるため、対象を確認してください。チェッカーで内容を確認して参照版を更新し、シミュレーターの除外確認が表示された場合は、その対象を確認してから進めます。

保存競合や保存領域エラーが出たとき

同じ所持品を複数のタブで同時に編集すると、保存競合が起こることがあります。未保存の内容を JSON で退避し、「最新の保存データを読み込む」で状態を確認してから統合してください。保存領域を利用できない表示の場合はブラウザのプライバシー設定も確認します。

データの出典と報告

装備・スキル等のデータは MHDB、鑑定護石の検証は公開解析情報を参照しています。詳細は出典と更新方針をご覧ください。問題が続く場合は、カタログ版、操作手順、具体的な入力を問い合わせ窓口へお知らせください。バックアップ全体や個人情報を公開する必要はありません。
